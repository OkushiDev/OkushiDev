## ⊹ Proyecto Destacado ⊹

### [Registro Vecinos App](https://github.com/OkushiDev)
*Full Stack Developer* · 2025 – 2026

Sistema web de gestión para juntas de vecinos con roles de **presidente** y **vecino**: registro de residentes, solicitud y aprobación de **certificados de residencia**, carga de documentos y auditoría de todas las mutaciones.

- **Backend:** FastAPI + SQLAlchemy 2.0 + Pydantic (validación de RUT), autenticación JWT con bcrypt.
- **Frontend:** React 19 + TypeScript + Vite + MUI, con lazy-loading y bundle inicial de ~654 kB.
- **Base de datos:** PostgreSQL 16 contenerizada con Docker; generación de PDF (ReportLab) y exportación a Excel (ExcelJS).
- **Calidad:** 49 tests automatizados (pytest y vitest) y documentación técnica completa.
